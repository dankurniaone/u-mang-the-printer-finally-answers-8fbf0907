A make.fun entry for [The Printer Finally Answers](https://make.fun/competitions/u-mang-the-printer-finally-answers-8fbf0907): one line, in the office printer's own voice, as its comeback to everyone staring at it.

## The line

> I have been out of cyan since March, and nobody noticed until the pie chart turned grey.

88 characters, one sentence, one read. The printer speaks first person, weary and literal, counting time the way a machine counts sheets, and the punchline is a concrete visual instead of the recycled paper-jam line.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`.

```bash
python3 main.py --check        # validate against the 1-240 char gate
python3 main.py --tournament   # print the candidate tournament table
python3 main.py --self-test    # write twice, compare bytes
python3 main.py                # write to /output/entry.txt
```
